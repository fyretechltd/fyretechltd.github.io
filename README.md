# fyretechltd.github.io

Website for Fyre Tech Ltd, published at https://fyretech.co.uk by GitHub Pages using its built-in Jekyll build. There are no plugins, no scripts and no external files.

## Structure

```
_config.yml              site settings
_layouts/default.html    shared page structure (header, main, footer)
_layouts/app.html        layout for app pages written in Markdown
_includes/               header, footer and navigation links
_data/projects.yml       list shown on /projects/
assets/css/style.css     the only stylesheet
index.md                 /
projects.md              /projects/
contact.md               /contact/
privacy.md               /privacy/
sitemap.xml              generated by Jekyll
robots.txt, CNAME
```

## Adding an app

Each app gets its own folder at the top level, e.g. `/my-app/`.

Do not use these names for an app folder: `projects`, `contact`, `privacy`, `assets`. Folders starting with `_` or `.` are ignored by Jekyll.

### Option 1: Markdown

```
my-app/index.md
my-app/support.md
my-app/privacy.md
```

`my-app/index.md`:

```markdown
---
layout: app
title: My App
description: One-line description.
icon: /my-app/icon.png         # optional
app_store: https://apps.apple.com/...      # optional
google_play: https://play.google.com/...   # optional
---

A short description of what the app does.
```

`my-app/support.md` and `my-app/privacy.md` use `layout: default` with `permalink: /my-app/support/` and `permalink: /my-app/privacy/`.

### Option 2: Standalone HTML

Drop a static site into `my-app/`. HTML files **without** front matter are published unchanged. Use relative links (`style.css`) or links that include the folder (`/my-app/style.css`).

### List it on /projects/

Add an entry to `_data/projects.yml`:

```yaml
- name: My App
  description: One-line description.
  url: /my-app/
```
